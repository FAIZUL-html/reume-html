# HTML Resume Template

A simple and clean HTML template for creating your personal resume or CV. This template lets you showcase your skills, education, and contact information in a web-friendly format. Easy to customize and printable to PDF.

## Features

- Clean HTML layout with sections for About, Skills, Education, and Contact
- Responsive design for different screen sizes
- Easy to edit and personalize
- Printable directly from the browser

## Preview

Open the `style.html` file in any browser to see your resume.
